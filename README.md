# Golden Valley

Dashboard financeiro em HTML (Chart.js) para análise de Valuation, DRE, FCL, WACC e Balanço.

## Publicação no GitHub Pages

Após o push para a branch `main`, ative em:

1. `Settings` -> `Pages`
2. Source: `Deploy from a branch`
3. Branch: `main` e pasta `/ (root)`

URL esperada:

`https://abarakus11.github.io/Golden-Valley/`
